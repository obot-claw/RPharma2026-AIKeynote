# Visual Asset Plan

Purpose: track the transition from text-heavy draft slides to image-backed slides.

## Directories

- `assets/screenshots/` - public screenshots from tools, demos, package sites, GitHub workflows, or approved examples.
- `assets/images/` - generated illustrations, diagrams, or non-screenshot visuals.

## Initial visual backlog

- Clinical trial workflow diagram: setup -> conduct -> closeout -> submission.
- SafetyGraphics / gsm.safety screenshots from public demos.
- obot/OpenClaw orchestration screenshot or diagram.
- Agentic engineering lifecycle diagram: plan -> implement -> test -> review -> release.
- GitHub issue/PR workflow screenshot showing Project / Requirement / Task structure.
